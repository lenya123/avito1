# Навигация приложения

> **B2B SaaS-коробка (single-tenant).** Клиентского веб-сайта нет — заказы от конечных покупателей принимаются через Telegram customer-bot (Этап 3). Система состоит из панели владельца и PWA отправщика.

## Публичные страницы

| URL              | Описание                                              |
| ---------------- | ----------------------------------------------------- |
| `/`              | Лендинг с двумя CTA: «Панель владельца» и «Отправщик» |
| `/owner/login`   | Логин владельца/админа                                |
| `/shipper/login` | Логин отправщика                                      |

---

## Панель владельца

Главная рабочая панель (роли `owner` и `admin`).

| Раздел           | URL                | Описание                                                                                                                         |
| ---------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| **Dashboard**    | `/owner/dashboard` | Метрики, графики, алерты                                                                                                         |
| **Клиенты**      | `/owner/clients`   | Список клиентов оптовика с фильтрами (vibe/frozen/blocked/top), карточка `/owner/clients/[id]` с табами заказы/платежи/переписка |
| **Товары**       | `/owner/products`  | Каталог. Создание `/owner/products/new`, edit `/owner/products/[id]`                                                             |
| **Заказы**       | `/owner/orders`    | Все заказы системы, детали `/owner/orders/[id]`                                                                                  |
| **Отправщики**   | `/owner/shippers`  | Список отправщиков, детали/статистика `/owner/shippers/[id]`                                                                     |
| **Аналитика**    | `/owner/analytics` | Графики, топы, тренды                                                                                                            |
| **Финансы**      | `/owner/finance`   | Выручка, расходы, чистая прибыль                                                                                                 |
| **Выплаты**      | `/owner/payouts`   | Управление выплатами отправщикам (pending/paid, подтверждение перевода)                                                          |
| **AI-продажник** | `/owner/ai-sales`  | AI-менеджер продаж + `/owner/ai-sales/analytics`, `/owner/ai-sales/settings`                                                     |
| **Безопасность** | `/owner/security`  | Per-customer риск-панель (return_rate, cancel_rate, debt/limit) + лента fraud-алертов + ручной запуск детекторов                 |
| **Настройки**    | `/owner/settings`  | Бренд + лимит +ВАЙБ + шаблон реквизитов + ферма карт (вкладка). Берёт из `settings` + `business_settings`                        |
| **Партнёры**     | `/owner/partners`  | CRUD партнёров (поставщики чужих товаров), invite-ссылки, долг по комиссии. Детали `/owner/partners/[id]` (Stage 3.8).           |
| **Ещё**          | `/owner/more`      | Вторичные пункты меню                                                                                                            |

## PWA отправщика

Роль `shipper` (также доступно owner/admin).

| Раздел        | URL                 | Описание                                  |
| ------------- | ------------------- | ----------------------------------------- |
| **Главная**   | `/shipper`          | Сводка: товары к сборке, в пути, возвраты |
| **Склад**     | `/shipper/stock`    | Товары и размеры, инвентарь               |
| **Заработок** | `/shipper/earnings` | История выплат, pending-сумма             |
| **Профиль**   | `/shipper/profile`  | Профиль, аватар                           |

Моно-бизнес: отправщик видит все заказы (изоляция по `seller_id` убрана в Stage 1).

## Удалено в пивоте

- **Клиентский веб-сайт** `/(client)/*` — каталог, заказы, подписка, рефералы, витрины магазинов. Перенесён в `archive/legacy-client-ui/`.
- **Панель селлера** `/(seller)/*` — мульти-селлер модель вырезана; один владелец = одна установка.
- **owner/sellers, owner/platform/\*, owner/subscriptions** — управление платформой не нужно в single-tenant.

## Telegram (без веб-интерфейса)

- **customer-bot** (Stage 3, env `TELEGRAM_CUSTOMER_BOT_TOKEN`, webhook
  `/api/telegram/customer`) — `/start` регистрирует в `customers`, каталог
  (категории → товары → размеры), wizard заказа (служба → город → ПВЗ →
  подтверждение), автоматические реквизиты + приём фото чека, «💳 Оплатить
  долг» для +ВАЙБ-клиентов, push-уведомления о статусах.
- **owner-bot** (Stage 10, env `TELEGRAM_OWNER_BOT_TOKEN`, webhook
  `/api/telegram/owner`) — управленческие команды (`/vibe`, `/block`,
  `/stats`). Также используется для постинга карточек заказов в топик
  «Заказы» супергруппы `TELEGRAM_ORDERS_GROUP_ID` (Stage 3.7) и алертов
  владельцу.
- **shipper-bot** (env `TELEGRAM_SHIPPER_BOT_TOKEN`, webhook
  `/api/telegram/shipper`) — нотификации отправщику о заказах и выплатах.
- **partner-bot** (Stage 3.8, env `TELEGRAM_PARTNER_BOT_TOKEN`, webhook
  `/api/telegram/partner`) — партнёр-поставщик получает deep-link
  приглашение (`t.me/<bot>?start=<invite_token>`), затем бот присылает
  ему карточки заказов по его товарам с кнопками «📝 Ответить
  реквизитами» / «❌ Нет в наличии» / «✅ Получил» / «✏️ Указать трек».
