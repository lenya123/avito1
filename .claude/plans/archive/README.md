# Архив планов

Планы B2C-фазы продукта, неактуальные после пивота на B2B SaaS-коробку (см. `.claude/plans/dapper-hugging-wozniak.md`).

Сохранены для исторической справки — отдельные решения могут пригодиться при проработке похожих механик в новой модели.

- **return-pickup-design.md** — механика пунктов выдачи для возвратов клиентов B2C-платформы. Возвраты в новой модели переработаны в Этапе 3 (см. актуальный план), но часть идей по UX возвратов может быть полезна.
